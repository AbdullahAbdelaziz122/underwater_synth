# Underwater Data Synthesis

This repository provides tools and scripts for generating synthetic underwater data, specifically tailored for submarine and torpedo scenarios. The purpose is to facilitate research, development, and testing of underwater detection, tracking, and classification algorithms by providing realistic simulated datasets.

## Features

- **Synthetic Data Generation:** Create customizable datasets simulating underwater environments, including submarine and torpedo movements.
- **Scenario Configuration:** Define parameters such as object trajectories, sensor placements, and environmental conditions.
- **Extensible Framework:** Easily add new object types or environmental effects.

- **Bellhop Environment Configuration:** Set up realistic underwater environments using Bellhop for accurate signal propagation modeling and data generation.

## Usage

1. Clone the repository:
    ```bash
    git clone https://github.com/AbdullahAbdelaziz122/underwater_synth.git
    ```
2. Follow the instructions in the relevant scripts to generate datasets.

## Applications

- Training machine learning models for underwater object detection.
- Benchmarking tracking algorithms.
- Simulating sensor data for sonar and acoustic systems.
